## What is LearnAI?

LearnAI is a structured, hands-on curriculum covering machine learning and
artificial intelligence from first principles through agentic AI systems —
classical ML, deep learning, NLP/LLMs, context engineering, RAG, LangChain,
and LangGraph.

This is a Phase 0 scaffold. Head to [K-Nearest Neighbors](/docs/courses/classical-ml/knn)
for a placeholder lesson demonstrating the content pipeline end to end.
