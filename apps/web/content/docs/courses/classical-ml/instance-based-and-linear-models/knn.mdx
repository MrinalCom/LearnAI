## Overview

K-Nearest Neighbors (KNN) is one of the simplest supervised learning algorithms.
To classify a new point, it looks at the `k` closest labeled points in the
training set and takes a majority vote (or averages, for regression).

## Why start here?

KNN requires no training step, is easy to visualize in 2D, and cleanly
introduces core ML concepts: distance metrics, the bias-variance tradeoff
(via choice of `k`), and the importance of feature scaling.
