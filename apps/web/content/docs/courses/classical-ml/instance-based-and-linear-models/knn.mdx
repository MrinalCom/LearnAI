## Overview

K-Nearest Neighbors (KNN) is one of the simplest supervised learning algorithms.
To classify a new point, it looks at the `k` closest labeled points in the
training set and takes a majority vote (for regression, it averages their
values instead).

There's no training phase — KNN just memorizes the training data and does all
the work at prediction time. That makes it easy to reason about, but expensive
to query as the dataset grows.

Notice what happens as you move the slider:

- **Small `k` (e.g. 1)** — the boundary is jagged and closely tracks individual
  points. Low bias, high variance: sensitive to noise and outliers.
- **Large `k` (e.g. 15)** — the boundary smooths out, ignoring local structure
  in favor of the global class balance. Higher bias, lower variance.

This is the bias-variance tradeoff, and `k` is the knob that controls it.

## Why start here?

KNN requires no training step, is easy to visualize in 2D, and cleanly
introduces core ML concepts that reappear throughout this course:

- **Distance metrics** — KNN typically uses Euclidean distance, but Manhattan,
  cosine, and other metrics matter a lot for high-dimensional or sparse data.
- **The bias-variance tradeoff** — via the choice of `k`, as shown above.
- **Feature scaling** — since KNN is purely distance-based, a feature measured
  in the thousands (e.g. income) will dominate one measured in single digits
  (e.g. age) unless you standardize your features first.

## Choosing k

There's no universally correct `k`. In practice you pick it with
cross-validation (covered later in [Model Evaluation](/docs/courses/classical-ml)):
try a range of values, measure validation accuracy for each, and pick the `k`
that generalizes best — not just the one that fits the training set closest.

A common starting heuristic is `k ≈ √n`, where `n` is the number of training
examples, adjusted up or down based on how noisy the data is.
